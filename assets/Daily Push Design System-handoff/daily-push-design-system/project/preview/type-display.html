Rules
  • Display only — headings, numerals, short UI labels. Never body text.
  • Never fake-bold. The font ships 400 only; synthetic weights distort the design.
  • Never italicize. No italic cut exists; synthetic italic looks sheared.
  • Pair with Inter for body, sub-labels, form input text, and any paragraph ≥ 2 lines.
  • Works best 18px+. Below that, switch to Inter for legibility.
